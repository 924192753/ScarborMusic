# ScarborMusic 压缩包部署教程

使用本仓库生成的 **`scarbormusic-deploy-YYYYMMDD.tar.gz`**，在腾讯云服务器上通过 **公网 IP + HTTP** 部署。

| 项目 | 值 |
|------|-----|
| 压缩包 | `dist/scarbormusic-deploy-YYYYMMDD.tar.gz`（本地打包） |
| 公网 IP | **159.75.87.182** |
| 网站地址 | **http://159.75.87.182** |

---

## 第一步：本地生成压缩包（开发机）

在项目根目录执行：

```bash
chmod +x scripts/package-release.sh
./scripts/package-release.sh
```

生成文件示例：

```
dist/scarbormusic-deploy-20260525.tar.gz
```

将上述 `.tar.gz` 用 **scp / WinSCP / 腾讯云控制台上传** 传到服务器。

---

## 第二步：服务器安装 Docker（仅首次）

SSH 登录服务器（CentOS Stream 9 / Rocky 9）：

```bash
sudo dnf update -y
sudo dnf install -y curl vim tar gzip
sudo dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
sudo dnf install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
```

重新登录 SSH 后执行 `docker compose version` 确认可用。

**安全组放行**：22（SSH）、80（网站）。可选 3001（Grafana，建议仅管理员 IP）。

---

## 第三步：解压项目

```bash
# 假设压缩包在 /opt
sudo mkdir -p /opt/scarbormusic
sudo tar -xzf /opt/scarbormusic-deploy-20260525.tar.gz -C /opt/scarbormusic
cd /opt/scarbormusic

# 确认存在主文件
ls docker-compose.prod.yml scripts/deploy-ip.sh .env.production.ip.example
```

若解压后多了一层子目录，请 `cd` 到包含 `docker-compose.prod.yml` 的那一层。

---

## 第四步：配置环境变量

```bash
cp .env.production.ip.example .env.production
vim .env.production
```

**必须修改**（把所有 `change-me` 换成强密码）：

| 变量 | 填写说明 |
|------|----------|
| `MYSQL_ROOT_PASSWORD` | MySQL root 密码 |
| `MYSQL_PASSWORD` | 应用库密码（与下面 DATABASE_URL 一致） |
| `DATABASE_URL` | `mysql://scarbormusic:<密码>@mysql:3306/scarbormusic` |
| `JWT_SECRET` | `openssl rand -hex 32` |
| `JWT_REFRESH_SECRET` | 再执行一次 `openssl rand -hex 32` |
| `S3_ACCESS_KEY` / `S3_SECRET_KEY` | MinIO 密钥（自定强密码） |
| `GRAFANA_ADMIN_PASSWORD` | Grafana 密码 |

**保持不动**（已为公网 IP 配好）：

```env
DOMAIN=159.75.87.182
NEXT_PUBLIC_APP_URL=http://159.75.87.182
COOKIE_SECURE=false
S3_PUBLIC_URL=http://159.75.87.182/storage
```

---

## 第五步：一键部署

```bash
chmod +x scripts/*.sh
./scripts/deploy-ip.sh
```

首次构建约 **10～30 分钟**（视 CPU 与网速而定）。

**不要**执行 `scripts/init-ssl.sh`（当前为 HTTP，无 HTTPS）。

---

## 第六步：验证

```bash
./scripts/health-check.sh
curl -I http://127.0.0.1/health
```

浏览器打开：**http://159.75.87.182**

- 注册 / 登录应正常（依赖 `COOKIE_SECURE=false`）
- 上传封面后，图片地址应为 `http://159.75.87.182/storage/...`

---

## 常见问题

| 现象 | 处理 |
|------|------|
| `deploy-ip.sh` 提示 change-me | 编辑 `.env.production` 替换占位密码后重跑 |
| 能开页面无法登录 | 确认 `COOKIE_SECURE=false` 且 URL 为 `http://` |
| 502 | `docker logs scarbormusic-web`，等 MySQL 就绪后 `./scripts/restart.sh web` |
| 图片不显示 | 确认 `S3_PUBLIC_URL=http://159.75.87.182/storage` |

修改 `.env.production` 后重建 Web：

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production build web
docker compose -f docker-compose.prod.yml --env-file .env.production up -d web nginx
```

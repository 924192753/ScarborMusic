# ScarborMusic 服务器部署教程（公网 IP + HTTP）

适用于：**腾讯云 CentOS**，通过压缩包上传部署。当前生产模式为 **公网 IP + HTTP**，无需域名与 HTTPS。

| 项目 | 值 |
|------|-----|
| 公网 IP | **159.75.87.182** |
| 访问地址 | **http://159.75.87.182** |
| Grafana | http://159.75.87.182:3001（建议仅管理员 IP 访问） |

---

## 一、前置条件

### 1. 服务器配置建议

| 项目 | 最低 | 推荐 |
|------|------|------|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 系统盘 | 40 GB | 80 GB+ |
| 系统 | CentOS Stream 9 / Rocky 9 | 同左 |

### 2. 安全组 / 防火墙

必须放行：

- **80** — 网站（HTTP）
- **22** — SSH

可选（仅管理员 IP）：

- **3001** — Grafana 监控

**不需要**放行 443（当前未启用 HTTPS）。

### 3. 安装 Docker（执行一次）

```bash
sudo dnf update -y
sudo dnf install -y curl vim tar gzip
sudo dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
sudo dnf install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
# 重新登录 SSH 后生效
```

## 三、配置环境变量

```bash
cp .env.production.ip.example .env.production
vim .env.production
```

**必须修改**（将所有 `change-me` 换成强密码）：

| 变量 | 说明 |
|------|------|
| `DOMAIN` | 保持 `159.75.87.182` |
| `NEXT_PUBLIC_APP_URL` | 保持 `http://159.75.87.182` |
| `COOKIE_SECURE` | 保持 `false`（HTTP 登录必需） |
| `MYSQL_ROOT_PASSWORD` / `MYSQL_PASSWORD` | MySQL 密码 |
| `DATABASE_URL` | 密码与 `MYSQL_PASSWORD` 一致 |
| `JWT_SECRET` / `JWT_REFRESH_SECRET` | `openssl rand -hex 32` |
| `S3_ACCESS_KEY` / `S3_SECRET_KEY` | MinIO 密钥 |
| `S3_PUBLIC_URL` | 保持 `http://159.75.87.182/storage` |
| `GRAFANA_ADMIN_PASSWORD` | Grafana 密码 |

生成随机密钥：

```bash
openssl rand -hex 32
```

---

## 四、一键部署

```bash
chmod +x scripts/*.sh
./scripts/deploy-ip.sh
```

`deploy-ip.sh` 会检查占位符密码、构建镜像、启动全部服务（**不启动 certbot**）。

若已手动配置好 `.env.production`，也可：

```bash
./scripts/deploy.sh
```

**不要**执行 `init-ssl.sh`（无域名 HTTPS）。

## 五、验证

```bash
./scripts/health-check.sh
curl -I http://127.0.0.1/health
curl -I http://159.75.87.182/
```

浏览器打开：**http://159.75.87.182**

上传的封面/音频通过 Nginx 路径 `/storage/` 访问，与 `S3_PUBLIC_URL` 一致。

## 六、常用运维

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production ps
docker logs -f scarbormusic-web
./scripts/restart.sh web
./scripts/mysql-backup.sh
```

修改 `.env.production` 后需重建 Web：

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production build web
docker compose -f docker-compose.prod.yml --env-file .env.production up -d web nginx
```

## 七、故障排查

| 现象 | 处理 |
|------|------|
| 能打开页面但无法登录 | 确认 `COOKIE_SECURE=false`，`NEXT_PUBLIC_APP_URL` 为 `http://` |
| 502 Bad Gateway | `docker logs scarbormusic-web`，等待 MySQL 就绪 |
| 图片/音频无法显示 | 确认 `S3_PUBLIC_URL=http://159.75.87.182/storage`，访问 `/storage/` 是否 200 |
| deploy-ip 提示 change-me | 编辑 `.env.production` 替换所有占位密码 |

---

## 八、可选：将来改用域名 + HTTPS

1. 修改 `.env.production` 为域名与 `https://` URL，`COOKIE_SECURE=true`
2. 在 `docker-compose.prod.yml` 的 nginx 中恢复 `443:443` 端口映射
3. `docker compose ... --profile ssl up -d`
4. `./scripts/init-ssl.sh`

详见 `DEPLOYMENT.md`。

---

## 九、安全提醒

1. 勿将 `.env.production` 上传到公开仓库  
2. HTTP 传输密码会被窃听，仅适合内测；正式上线建议域名 + HTTPS  
3. Grafana 3001 端口勿对全网开放

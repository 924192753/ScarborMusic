# ScarborMusic 服务器部署教程（压缩包上传）

适用于：**腾讯云 / 任意 Linux 云服务器**，通过压缩包上传部署（无需 Git）。

---

## 一、前置条件

### 1. 服务器配置建议

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 系统盘 | 40 GB | 80 GB+ |
| 操作系统 | **CentOS Stream 9** / Rocky 9 / AlmaLinux 9 | 同左 |
| 带宽 | 3 Mbps | 5 Mbps+ |

### 2. 网络与域名

- 已购买云服务器，可通过 **SSH** 登录（22 端口）
- 安全组 / 防火墙已放行：**80**、**443**（网站）
- 可选：放行 **3001**（Grafana 监控，建议仅管理员 IP 访问）
- 已有域名，且 **A 记录** 已解析到服务器公网 IP（申请 HTTPS 时需要）

### 3. 必须安装的软件（在服务器上执行一次）

```bash
# 更新系统
sudo dnf update -y

# 基础工具
sudo dnf install -y curl vim tar gzip

# Docker + Compose 插件
sudo dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
sudo dnf install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

sudo systemctl enable --now docker
sudo usermod -aG docker $USER
# 重新登录 SSH 后 docker 无需 sudo
```

验证：

```bash
docker --version
docker compose version
```

### 4. 本地准备

- 压缩包：`scarbormusic-deploy-YYYYMMDD.tar.gz`（由 `scripts/package-release.sh` 生成）
- 上传工具：**scp**、**sftp**、WinSCP、Xshell 文件传输等

## 二、上传压缩包到服务器

### 方式 A：scp（本机 Linux / macOS）

```bash
scp scarbormusic-deploy-20260525.tar.gz root@<服务器IP>:/opt/
```

### 方式 B：先传到用户目录再移动

```bash
# 上传到 /root 或 /home/你的用户
scp scarbormusic-deploy-20260525.tar.gz user@<服务器IP>:~/

# SSH 登录后
ssh user@<服务器IP>
sudo mkdir -p /opt/scarbormusic
sudo tar -xzf ~/scarbormusic-deploy-20260525.tar.gz -C /opt/scarbormusic
# 若解压后多了一层目录，进入实际项目根目录
cd /opt/scarbormusic
ls -la   # 应看到 docker-compose.prod.yml、package.json、scripts/
```

> 若解压后文件在子目录 `ScarborMusic/` 下，请 `cd` 到包含 `docker-compose.prod.yml` 的那一层。

## 三、配置环境变量

```bash
cd /opt/scarbormusic   # 项目根目录

cp .env.production.example .env.production
vim .env.production    # 或 nano
```

**必须修改的项：**

| 变量 | 说明 |
|------|------|
| `DOMAIN` | 你的域名，如 `music.example.com` |
| `NEXT_PUBLIC_APP_URL` | `https://你的域名` |
| `MYSQL_ROOT_PASSWORD` | MySQL root 强密码 |
| `MYSQL_PASSWORD` | 应用数据库用户密码 |
| `DATABASE_URL` | 保持 `mysql://scarbormusic:<密码>@mysql:3306/scarbormusic` |
| `JWT_SECRET` | 随机字符串 ≥32 位 |
| `JWT_REFRESH_SECRET` | 随机字符串 ≥32 位 |
| `S3_ACCESS_KEY` / `S3_SECRET_KEY` | MinIO 密钥（自行生成强密码） |
| `GRAFANA_ADMIN_PASSWORD` | Grafana 登录密码 |
| `CERTBOT_EMAIL` | Let's Encrypt 邮箱 |

生成随机密钥示例：

```bash
openssl rand -hex 32
```

## 四、一键部署

```bash
chmod +x scripts/*.sh

# 校验 compose 配置
docker compose -f docker-compose.prod.yml --env-file .env.production config

# 构建并启动（首次约 10~30 分钟，取决于网速与 CPU）
./scripts/deploy.sh
```

`deploy.sh` 会：

1. 构建 `web`、`nginx` 镜像  
2. 启动 MySQL、Redis、MinIO  
3. 启动应用、Nginx、监控与日志组件  
4. 自动执行数据库迁移

## 五、配置 HTTPS（推荐）

确保域名已解析到本机且 **80 端口** 可访问后：

```bash
./scripts/init-ssl.sh
```

证书自动续期（可选，加入 crontab）：

```bash
0 3 * * * /opt/scarbormusic/scripts/cert-renew.sh >> /var/log/scarbormusic-cert.log 2>&1
```

## 八、故障排查

| 现象 | 处理 |
|------|------|
| `docker: command not found` | 安装 Docker，重新登录 SSH |
| 构建很慢 / 失败 | 检查磁盘空间 `df -h`，内存 `free -h` |
| 502 Bad Gateway | `docker logs scarbormusic-web`，等待 MySQL 就绪后重启 web |
| 无法申请证书 | 确认域名解析、80 端口、防火墙 |
| 上传文件失败 | 检查 Nginx `client_max_body_size 100m`（已默认配置） |

更详细说明见项目根目录 **`DEPLOYMENT.md`**（英文架构与 CI/CD）。

## 九、目录结构说明（解压后）

```
/opt/scarbormusic/
├── apps/web/Dockerfile      # Web 镜像构建
├── docker-compose.prod.yml  # 生产 Compose（主入口）

├── docker/monitoring/       # Prometheus + Grafana
├── docker/logging/          # Loki + Promtail
├── packages/prisma/         # 数据库 Schema 与迁移
├── scripts/                 # deploy / backup / ssl 等
├── .env.production.example
└── docs/服务器部署教程.md   # 本文档
```

## 十、安全提醒

1. **不要**将 `.env.production` 提交到公开仓库或发给他人  
2. 生产环境务必使用强密码与独立 JWT 密钥  
3. Grafana 端口不要对公网全网开放  
4. 定期执行 `mysql-backup.sh` 并异地保存备份
